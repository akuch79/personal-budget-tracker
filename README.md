
# Personal Budget & Expense Tracker

## Project Description

The Personal Budget & Expense Tracker is a simple website designed to help individuals track their income and expenses in one place.

This is the first version of the project, focusing on HTML structure and basic CSS styling.

## Features

- Website heading and introduction
- Add Expense section
- Expense name input
- Amount input
- Category input
- Your Expenses placeholder section
- Basic CSS styling

## Technologies Used

- HTML5
- CSS3
